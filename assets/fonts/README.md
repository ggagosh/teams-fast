# Bundled font

`NotoSansGeorgian.ttf` is the unmodified Noto Sans Georgian variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansgeorgian). Its upstream filename is `NotoSansGeorgian[wdth,wght].ttf`.

It is distributed under the SIL Open Font License in [OFL.txt](OFL.txt). TeamsFast embeds it as a fallback for both proportional and monospace text so Georgian works in inputs and messages on every supported platform, without relying on locally installed fonts.
